# Personal Control Center

## О проекте

Personal Control Center — веб-интерфейс для мониторинга, управления и автоматизации компьютерных устройств.

На главной странице представлены подключаемые устройства и компьютерные среды, для которых отображается основная информация: название, операционная система, характеристики, назначение и текущий статус.

## Что находится на странице

Страница содержит:

- шапку сайта с названием проекта и навигацией;
- главный информационный блок с кратким описанием проекта;
- форму поиска и фильтрации устройств по названию и операционной системе;
- каталог из шести карточек устройств;
- изображения устройств;
- основные характеристики каждого устройства;
- раздел с информацией о проекте;
- подвал страницы.

В каталоге представлены следующие устройства и среды:

- Gigabyte G6 MF;
- Acer Aspire A315-53G;
- Desktop PC;
- Virtual Machine;
- Ubuntu Environment;
- Test Node.

## Лабораторная работа №1

В ходе первой лабораторной работы была разработана статическая клиентская часть веб-приложения Personal Control Center.

Были выполнены следующие действия:

- создана структура HTML-страницы;
- использованы семантические элементы HTML: `header`, `nav`, `main`, `section`, `article`, `footer`;
- создан каталог из шести карточек устройств;
- добавлены изображения и текстовые характеристики устройств;
- создана форма поиска и фильтрации;
- для полей формы добавлены связанные элементы `label`;
- стили вынесены в отдельный CSS-файл;
- для расположения карточек использован CSS Grid;
- для навигации и элементов формы использован Flexbox;
- реализована адаптивная вёрстка для разных размеров экрана;
- добавлены состояния `hover` и `focus` для интерактивных элементов;
- оформлены шапка, карточки, форма и подвал страницы.
